Sorting in Python is simple and flexible.  
You can use `sorted()` to return a new sorted list, or `.sort()` to sort a list in place.  
The `key` parameter lets you define custom rules, like sorting by length or absolute value.  
Tuples and dictionaries can be sorted with `lambda` functions.  
For dataframes, Pandas provides `sort_values()` to sort by one or multiple columns.
